XMenu RVGL Chaos

Trainer menu and Chaos Mod for RVGL 23.1030a1 (64-bit).

Download XMenu 0.1.0 (win64, 1.6 MB)

Install

RVGL Launcher: close RVGL, then copy the rvgl_win64 and rvgl_assets folders from the zip into %LOCALAPPDATA%\rvmm\packs (merge and replace).

Standalone: copy the contents of rvgl_win64 and rvgl_assets next to rvgl.exe.

To remove it, delete version.dll and XMenu.dll.

Keys

F7 - open/close menu
Numpad 8/2 - up/down
Numpad 4/6 - change value
Numpad 5 - select
Numpad 0 - back
F6 - airbreak (W/S up/down, Numpad 8/2/4/6 move)
Hold middle mouse - fly where you look (if turned on)
; - unlimited ammo
= - no car collision
- - reset car
] (hold) - speed boost
Controller: RB + D-Pad Right opens the menu, A select, B back

Keys are for a US keyboard and can be changed in ZMenuRVGL.ini.

Notes

Only RVGL 23.1030a1 is supported. XMenu turns itself off in online lobbies.

Features

General

  • Works with standalone RVGL and the RVGL Launcher.
  • Looks like the original ZMenu: game font, numpad controls, hints, controller support.
  • Settings are saved in ZMenuRVGL.ini and the ZMenu folder. Old ZMenu settings still work.
  • On other RVGL versions the menu opens, but game features stay off.
  • Online: XMenu closes, turns off all cheats and Chaos, and stays locked until you leave the lobby.

Teleports

  • 10 save slots per track (save, load, save to .ini)
  • Teleport to race start
  • Teleport to a random car

Spawn

  • Spawn any car, as many as the car limit allows
  • Pick the AI type: CPU, Local, Remote, Ghost, Replay, Frontend, Display, CalcStats
  • Spawn next to you or on the start grid
  • Change your own car to any car mid-race
  • Spawn any object and select it
  • Move, rotate, teleport to or delete the selected object

Racers

  • List of every racer in the race
  • For each racer: switch to, explode, teleport to, bring to you, reset
  • AI Control: let the AI drive your car

Options

  • Speedometer, coordinates, FPS, slow FPS, lock camera
  • Info display with 8 slots (car name, player, timestep, pointers, track, object count and more)
  • Car size (0.1x to 10x) and car gravity (0x to 10x)
  • Change the current race: laps, pickups on/off, random cars, random track
  • Cameras: Free, Rotatable, Top Down, GTA SA, GTA III
  • Airbreak, mouse fly, unlimited ammo, no car collision, AI Control
  • Up to 30 opponents in the menu
  • Clockwork Carnage grid (tight grid for lots of cars)
  • Raise the car limit to 512 (needs a restart)
  • Car counter

Menu Settings

  • Menu size, position, text size and UI scale
  • Airbreak speed, mouse fly speed, scroll speed
  • Hints, ignore keys when tabbed out, controller support
  • View keybinds, load keys from .ini, save and load settings

Experimental

  • Compatibility check for your RVGL build
  • Player and camera pointers, object and player counts, timestep

Chaos Mod

  • Turn Chaos on or off, quick setup
  • New effect every 5 to 600 seconds (30 is best), or trigger by key, or no timer
  • Filters: unstable, bad for streams, controversial, really unfair
  • Per effect: on/off, length, trigger, times used, custom sound (XMenuAssets/CustomEffectSounds/<id>.mp3)
  • See the effect order, trigger a random effect, export all effects to .csv
  • Look: presets (Default, Seems familiar..., Alternate Left/Right, Classic), position, size, alignment, stacking, background, timer bar colour, show hidden effects, hide UI
  • Sound: volume and sound test
  • Debug: trigger any effect by ID, stop all, refill timers, reset order
  • Settings saved in ZMenu_Chaos.ini, log in ZChaosEffectLog.log
